### 👨‍💻 About Me

Full-Stack Software Developer based in **Putrajaya, Malaysia**. I specialize in building, migrating, and maintaining production web applications using **Laravel, Python (Django/Flask), and React**, with an emphasis on security posture and AI/ML integrations.

---

### 🔭 What I'm Doing

* 🏛️ **Enterprise Systems:** Operating as Primary Application Administrator and Developer for government platforms (**iSKWAK** & **eVendor**) at KUSKOP, leading system migrations from Native PHP to Laravel.
* 🔒 **AI & Cybersecurity:** Developing intelligent threat detection systems like **SpamGuard** (SVM/CNN email analyzer) and **Job FakeNews.AI** (OSINT-driven misinformation detector).
* ⚡ **Architecture & Performance:** Designing multi-schema PostgreSQL database structures, role-based access control (RBAC) policies, and high-load background processing.
